# 2D Vacuum Cleaner Simulation (Mini-Game Prototype)

This project is a personal mini-game prototype built with **Unity** and **C#** to explore and practice 2D game mechanics, physics interactions, and level management systems.

## 🎯 About the Project
The primary goal of this project is to create a 2D vacuum cleaner simulation. It serves as an experimental sandbox for understanding key Unity concepts, such as:
- Custom 2D physics interactions and pull mechanics (Vacuum effect).
- Layer-based collision and interaction filtering.
- Basic gameplay loop and level management architecture.

## 🛠️ Built With
* **Engine:** Unity (2D)
* **Language:** C#
* **Version Control:** Git & GitHub
